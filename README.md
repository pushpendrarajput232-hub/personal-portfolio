# Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my skills, projects, certifications, education, and professional profile.

## 🌐 Live Website

[Visit My Portfolio](https://personal-portfolio-iota-nine-47.vercel.app)

## 👨‍💻 About

Hi, I'm Pushpendra Rajput, a Java Full Stack Developer and Computer Science Engineering student.

This portfolio website presents my technical skills, projects, certifications, education, and contact information in a clean and responsive interface.

## 🚀 Features

- Responsive personal portfolio website
- Modern and clean UI
- About Me section
- Skills section
- Education section
- Projects showcase
- Certifications section
- Contact form
- Backend API for contact messages
- MongoDB database integration
- Social media links
- Mobile-friendly design

## 🛠️ Technologies Used

### Frontend

- React.js
- Vite
- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS

### Deployment

- Vercel — Frontend
- Render — Backend
- MongoDB Atlas — Database
